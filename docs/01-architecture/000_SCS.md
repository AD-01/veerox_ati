# 1. Purpose

This document defines the service boundaries, responsibilities, public contracts, internal contracts, commands, queries, and inter-service communication model for the Veerox ATI Platform.

It specifies:

- Microservice Responsibilities
- Public Interfaces
- Internal Interfaces
- CQRS Contracts
- Commands
- Queries
- Domain Services
- Repository Contracts
- Event Publishers
- Event Consumers

This document SHALL be the authoritative implementation contract for all backend services.

---

# 2. Architectural Principles

Every service SHALL follow these principles:

- Single Responsibility
- Domain Ownership
- Loose Coupling
- Event-Driven Communication
- CQRS
- Clean Architecture
- Domain-Driven Design

A service SHALL own:

- Database Schema
- Business Rules
- APIs
- Events

A service SHALL NOT directly modify another service's database.
