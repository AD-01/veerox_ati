# 13. Identity Domain Events

Publishing Service

```text
identity-service
```

---

## 13.1 UserRegistered

### Description

Published when a new user successfully registers.

### Published By

Identity Service

### Consumers

- Organization Service
- Notification Service
- Audit Service
- Analytics Service

### Payload

```json
{
  "userId": "usr_xxx",
  "email": "user@example.com",
  "fullName": "John Doe",
  "registeredAt": "2026-08-07T10:00:00Z"
}
```

---

## 13.2 UserActivated

Published when an account becomes active.

Consumers

- Workspace Service
- Notification Service
- Audit Service

Payload

```json
{
  "userId": "usr_xxx",
  "activatedAt": "2026-08-07T10:00:00Z"
}
```

---

## 13.3 UserSuspended

Published when a user account is suspended.

Consumers

- Workspace Service
- Connector Service

- Audit Service

---

## 13.4 UserDeleted

Published after permanent user deletion.

Consumers

## 13.5 UserRoleChanged

Published whenever RBAC assignments change.

Payload


- Audit Service

# 17. Event Routing Matrix

| Event | Publisher | Primary Consumers |
|--------|-----------|-------------------|
| UserRegistered | Identity | Organization, Notification, Audit |
| OrganizationCreated | Organization | Workspace, Billing |
| WorkspaceCreated | Workspace | Strategy, Risk, Connector |
| ConnectorRegistered | Connector | Execution, Monitoring |
| TradingAccountConnected | Connector | Portfolio, Risk |
| SynchronizationCompleted | Connector | Monitoring, Analytics |

---

# 18. Idempotency Rules

The following events SHALL be idempotent:

- UserRegistered
- OrganizationCreated
- WorkspaceCreated
- ConnectorRegistered
- TradingAccountConnected
- SynchronizationCompleted

Consumers SHALL ignore duplicate event IDs.

# Chapter Summary

This chapter defines the foundational business events for:

- Identity
- Organization
- Workspace
- Connector
- Trading Account Synchronization

These events establish the event-driven backbone of the Veerox ATI platform, enabling loose coupling between services while ensuring reliable propagation of identity, tenancy, and infrastructure state changes throughout the system.
