# 15. Shared Schema

Schema Name

```text id="shared-schema"

```

The Shared Schema SHALL contain reusable reference data and cross-domain entities.

Business domains SHALL reference shared entities but SHALL NOT store business logic here.

# 19. Design Rules

The Identity and Organization schemas SHALL satisfy the following constraints:

- Every user SHALL have a globally unique identity.
- A user MAY belong to multiple organizations.
- An organization MAY contain multiple workspaces.
- Authentication data SHALL remain isolated from business data.
- Subscription state SHALL be managed independently of user identity.
- All tenant-aware tables SHALL reference `organization_id`.

These schemas form the identity and tenancy backbone of the Veerox ATI platform and are referenced by every other domain in the system.
