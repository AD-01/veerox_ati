# 20. Workspace Schema

Schema

```text id="workspace-schema"
workspace
```

The Workspace schema defines isolated trading environments inside an Organization.

A Workspace represents an independent trading ecosystem with its own:

- Trading Accounts
- Strategies
- Expert Advisors
- Risk Policies
- AI Configuration
- Market Preferences
- Automation Rules

A single Organization MAY contain multiple Workspaces.

# 23. Connector Communication Model

```text id="connector-model"
Veerox Platform
        │
        ▼
connector_commands
        │
        ▼
Veerox Agent
        │
        ▼
MetaTrader 5
        │
        ▼
Broker
        │
        ▼
connector_responses
        │
        ▼
Platform Event Bus
```

The database SHALL act as the persistent command and response ledger, while real-time communication MAY additionally use WebSockets or message queues.

---

# 24. Design Rules

The Workspace and Connector schemas SHALL satisfy the following constraints:

- A Workspace MAY own multiple Trading Accounts.
- A Connector MAY manage multiple MetaTrader terminals.
- A Trading Account SHALL belong to exactly one Workspace.
- Connector commands SHALL be immutable after execution.
- Account snapshots SHALL be append-only.
- Synchronization history SHALL never overwrite previous records.
